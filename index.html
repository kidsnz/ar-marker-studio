Where will it be used?

There is no distance to enter. You always frame a marker so it about fills the screen, and that is the only thing the tracker sees — measured on the real setup, a 5.5cm sticker at 8cm, a 12cm marker on a laptop screen at 20cm and a 72in painting at 2.9m all arrive the same size, spanning 185–225px of the tracker's canvas. So everything below is scored against that one target, widened to 150–250px for margin. The printed size only decides where you stand, which is what the line above works out.

Recommended settings

This starts on its own once an image is loaded. Each scale is generated for real and then scored, so the point counts and file sizes below are exact rather than estimated. Only -level=4 is tried: it wins on quality every time, and the other levels barely move the file size (that is set by the .fset3, which -level does not touch). Generating is slow — measured at 4.5s for a 320×228 image and 28.6s for 1920×1080 — so a big image takes minutes.

Based on the camera in ARnft's standard camera_para.dat (640×480, fx=609.4, so 55.4° across the long axis). A different lens shifts every distance proportionally. Closer than the fit distance the marker runs off the frame, so the counts there are optimistic.

Where the artwork is weak

How to get more points (everything below is measured, not guessed)
  • Scale up 2× with nearest-neighbour. By far the most effective. Interpolated scaling backfires.
  • Use -level=4. Going from the default 2 almost doubles the count.
  • Make the artwork coarser. Place large blocks apart from each other.
  • Put structure on all four edges. Top and bottom alone cannot fix horizontal position.
  • Go square or 4:3. Wide formats lose badly when the phone is held upright.
  • Keep the greys. Converting to pure black and white makes it far worse.

Confirmed not to help: thin lines, dithering, double or dashed lines, thin borders (under 3px after downscaling), changing -dpi (it only shifts the distance bands), and 4× scaling (worse than 2×).
